把音视频变成可编辑的字幕

双击即用的本地音视频工作台：字幕转写、时间轴校对、视频转码、媒体分析一站完成。 单个 Go 可执行文件 + 内嵌网页 + 本地识别引擎，数据不出本机，断网可用。

视听工作台 — 项目库

为什么不直接用现成方案

点击左侧导航查看对应模块

在线转写要上传素材

课程、会议、未发布内容上传云端，隐私与版权无法保证，还受上行带宽限制。

→ 识别引擎与模型全在本机运行，素材永不离开电脑。

云服务按分钟计费

一门 40 小时课程转下来动辄几十上百元，批量处理成本不可承受。

→ 本地模型一次下载、无限次使用，转多少集都不花钱。

命令行工具难上手

Whisper 类工具要装 Python、配环境、背参数，出错只有一行报错。

→ 双击 start.bat 自动构建；缺环境界面直接给出修复建议。

转完还要另找编辑器

生成 SRT 只是一半，对时间轴、改错字要在播放器和编辑器间反复切换。

→ 播放器 + 时间轴 + 逐句列表三联动，边听边改。

刷新 / 断电进度全丢

网页工具一刷新就白干，几百个视频的批量任务无法管理。

→ 每个文件落盘为「项目」，任务队列持久化，重启不丢。

换模型要换软件

很多工具与某识别模型深度绑定，想试新模型就得重装重学。

→ 可插拔适配器，本地 / 在线接口 / CLI 配置即可切换。

字幕转写

常驻 sherpa-onnx 引擎，模型只加载一次；SenseVoice 支持中英日韩粤并自带标点。

项目库

资源管理器式界面：文件夹树、回收站、多选、收藏、搜索，操作习惯与 Windows 一致。

字幕编辑

拖动色块整体移位、拖两端改起止、批量平移/替换/去重叠，时间码精确到毫秒。

视频转码

八种开箱预设，实时预览 ffmpeg 命令，成片自动入库。

媒体分析

编码、帧率、码率、声道一屏看清，浏览器可播性判断，原始 ffprobe JSON 可复制。

模型中心

模型列表含体积与语种，一键下载带进度、断点续传；完成即时生效，无需重启。

关于 / 下载

绿色便携、无需安装；备份或迁移就是复制整个程序目录。需要 ffmpeg、Python 3.10+（64 位）与 sherpa-onnx（双击 setup_local_asr.bat 自动安装）。

直接下载 推荐

从 GitHub Releases 获取 stt-sub.exe 与打包脚本，双击 start.bat 即可使用。

前往 Releases
  • 解压后双击 start.bat，首次运行自动构建
  • 「模型中心」下载语音模型（中文推荐 SenseVoice，约 200MB）

从源码构建

需要 Go 1.21+。

# 克隆并构建
git clone https://github.com/your-username/av-workbench
cd av-workbench
start.bat   # 自动 go build 并启动
  • go test ./... 运行单元测试
  • 前端在 server/web/，go:embed 打进二进制
组件用途获取方式
ffmpeg / ffprobe抽音、转码、媒体分析解压到 ffmpeg\bin\ 或加入 PATH
Python 3.10+（64 位）本地识别引擎运行环境python.org 下载，勾选 Add to PATH
sherpa-onnx本地语音识别双击 setup_local_asr.bat 自动安装
语音模型真正做识别的模型「模型中心」一键下载
